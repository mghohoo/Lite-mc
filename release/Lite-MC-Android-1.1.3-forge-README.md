## Forge 测试功能

下载 → 选择 Minecraft → Forge → 查看官方 Forge 版本（可选）→ 下载并安装。整合包版本页也可按包内指定的 Forge 版本创建新实例。

使用 Forge 官方 Maven 安装器和同源 SHA-1 校验，运行官方 CLIENT 安装与处理器流程，不把“复制了版本 JSON”当作安装完成。独立安装进程通过任务标识回传结果；成功后补齐游戏依赖，最后提交实例。安装失败不替换原来可用的实例。

支持范围是 Minecraft 1.13 及以后的 **1.x 现代安装格式**；旧版 1.12 Forge 暂未适配。NeoForge、Quilt、LiteLoader、OptiFine 仍未开放安卓自动安装，不冒充支持。此项限制不改变原版 26.x 的现有设备兼容判断。
